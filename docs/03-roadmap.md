# Roadmap

Rule: every phase ends with a usable app and a passed `phase-review`. No deadlines.

0. **Setup** — tools installed, Tauri + React + TS + Vite (pnpm), Tailwind v4 + shadcn, tokens, git.
1. **Shell** — layout (3 panes, responsive window), sidebar, Mod K palette, registry, themes, toasts, ToolLayout.
2. **Terminal Commands** — module + first content batch (see content-data skill).
3. **Formatters + Converters** — quick, high-value tools.
4. **CSS Visual Editors + Design**.
5. **GSAP & Scroll** — live previews (hardest UI part).
6. **Responsive Tools**.
7. **Database** — designer, generators, importers (Postgres first).
8. **My Library** — favorites, own snippets, VS Code snippet export.
9. **Integrations** — DB connection, run commands, VS Code extension.
10. **Polish** — installers (Windows MSI/NSIS, macOS DMG via GitHub Actions), auto-update, performance.
